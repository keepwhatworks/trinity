Contact

Everything about this site and Trinity Local runs through GitHub, in the open, where the answer helps the next person too.

Found a bug in Trinity?

Open an issue at github.com/keepwhatworks/trinity/issues. Include the output of trinity-local status if you can — it carries the health checks without carrying any of your content.

Questions, ideas, disagreements

Start a thread in Discussions. Disagreements are especially welcome: the whole product is built on the observation that the split between answers carries more information than any single answer.

Something wrong on this site?

A factual error in an essay, a number that no longer matches its instrument, a broken link — file it as an issue too. The site holds itself to the claims tracing to measurements, and a reader's correction is the cheapest instrument there is.

Teams and companies

Trinity is free for individuals. If you want it running across a team with support, read Trinity for teams and open an issue marked teams to start the conversation.
